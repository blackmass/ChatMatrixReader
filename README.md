# ChatMatrixReader
월드 오브 워크래프트 실시간 자동 번역기입니다.

와우용 애드온 **ChatMatrix**가 채팅을 화면 한쪽의 작은 색 칸(매트릭스)으로 그려 주고, **ChatMatrixReader**(이 프로그램)가 화면에서 그 칸을 읽어 글로 되돌려 번역한 뒤 게임 위의 투명한 창에 띄웁니다. 게임 파일, 메모리, DLL은 건드리지 않습니다.

> 이 프로그램은 Blizzard Entertainment와 제휴하거나 승인받은 것이 아닙니다. World of Warcraft는 Blizzard Entertainment의 상표입니다.

# 개발 방향성
- **가벼움**: 배포 용량이 작습니다. 무거운 프레임워크도, 번역용 AI도 안에 넣지 않습니다.
- **정확성**: OCR이나 AI Vision으로 화면을 "인식"하지 않습니다. 애드온이 채팅 데이터를 직접 가져와서 그대로 전달하기 때문에 글자가 100% 정확합니다.
- **간결하게**: 쓸데없는 디자인과 인터페이스를 최대한 숨깁니다. 번역된 글만 보이는 게 목표입니다.
- **학습성**: 영어를 지우고 한국어로 대체할 생각이 없습니다. 원문과 번역을 같이 보여 주는 게 기본입니다.
- **안정성**: exe로 배포하는 만큼 믿을 수 있게 하려고 한 것들이 있습니다.
  - 소스 전체 공개(MIT). DLL 삽입이나 메모리 접근 없음.
  - 릴리즈 zip 안의 `BUILD-INFO.txt`에 모든 파일의 SHA-256과 빌드한 커밋이 적혀 있습니다.
  - 음성인식 엔진과 모델은 받을 때마다 SHA-256을 확인합니다.
  - 쓰인 모든 라이브러리의 라이선스 목록(`THIRD-PARTY-NOTICES.txt`)을 같이 넣습니다.
  - 코드 서명은 하지 않았습니다(비용 때문). 그래서 Windows 경고가 뜰 수 있습니다.
- **독립성**: 설치 프로그램이 없습니다. 폴더 하나에 풀어서 실행하면 설정, 로그, 단어장, 글꼴까지 전부 그 폴더 안에서만 이뤄지고 레지스트리에는 아무것도 남기지 않습니다. 지우려면 폴더를 지우면 됩니다.

# 기능
- 채팅만 자동 감지해서 실시간 번역. 원문과 번역을 같이 표시, 순서 바꾸기, 채널별로 번역 방식을 다르게 설정.
- 번역창 여러 개. 창마다 채널, 글꼴, 크기, 투명도, 배경 흐림, 글자 외곽선을 따로 설정.
- **항상 위**, **와우 위에만** 보이기. 후자는 와우 중에 다른 작업을 해도 번역창이 가리지 않습니다.
- **클릭 관통**: 제목과 테두리가 사라져서 번역창만 깔끔하게 보이고 게임 조작을 방해하지 않습니다. Shift를 누른 채로 창에 마우스를 올리면 조작됩니다.
- 배경 투명, 글자 크기, 행간, 글꼴, 그림자 등을 맞추면 와우 화면에 위화감 없이 넣을 수 있습니다.
- **단어장**: 실시간으로 단어를 추가합니다. 구글 번역용과 AI 프롬프트용이 모두 기본 설정되어 있습니다.
- 문자열 규칙(정규식): 특정 글자가 들어 있으면 번역에서 빼거나 번역창에서 숨김 (예: 한글이 보이면 제외).
- **보내기**: 게임 중 `Shift+Enter` → 입력창이 뜨고 한글을 쓰면 번역된 영어가 클립보드에 복사됩니다 (옵션으로 자동 붙여넣기. 마지막 Enter는 직접).
- 다국어: 이미지 인식이 아니라 텍스트라서 구글이 감지하는 모든 언어가 번역됩니다. 인터페이스는 한국어/영어이고 다른 언어는 `locale` 폴더에 텍스트 파일만 넣으면 추가됩니다.
- 음성인식(STT): 디스코드, 와우 등 프로그램의 음성을 글로 바꿔서 번역합니다 (Windows).
- 옵션은 바꾸는 즉시 반영됩니다. 열기: 번역창의 ⚙, 트레이 아이콘, `Ctrl+Alt+O`.

# 설치
애드온과 프로그램, 둘 다 필요합니다.

**1. 애드온 (ChatMatrix)**
- <a href="https://www.curseforge.com/wow/addons/chatmatrix">CurseForge</a>에서 받아서 와우의 애드온 폴더에 넣습니다 (CurseForge 앱을 쓰면 자동).
- CurseForge의 최신 버전 승인이 늦어지면 <a href="https://drive.google.com/drive/u/0/folders/1vAJJ8w9MMW5qJzxfjg5qSktN5XhH77ow">구글 드라이브</a>에 올려 둡니다.

**2. 프로그램 (ChatMatrixReader) — Windows**
1. <a href="https://github.com/blackmass/ChatMatrixReader/releases">릴리즈 페이지</a>에서 `ChatMatrixReader-v<버전>-windows-x64.zip`을 받습니다 (소스코드 zip이 아닙니다).
2. 아무 폴더에나 풀고 `ChatMatrixReader.exe`를 실행합니다. 서명되지 않은 프로그램이라 Windows가 경고하면 "추가 정보 → 실행". `app` 폴더는 exe 옆에 그대로 두세요.
3. 필요한 것: Windows 10 또는 11. WebView2 런타임(Windows 11에는 들어 있고, 10에서 안 뜨면 Microsoft의 WebView2 런타임 설치).
4. 와우는 **창 모드 또는 전체 창 모드**로 실행합니다 (전용 전체 화면에서는 다른 창이 위에 안 보입니다).

**프로그램 — Mac (실험적)**
- Apple Silicon(M1 이후)용이고, **macOS 13 이상**이 필요합니다. 번역창, 항상 위, 와우 위에만, 클릭 관통, 매트릭스 읽기, 음성인식이 동작합니다. macOS 12 이하에서는 음성인식만 꺼지고 나머지는 그대로 됩니다.
- 개발자 등록을 하지 않아서 처음 실행할 때 보안 경고가 나옵니다 (우클릭 → 열기). 필요하면 터미널에서 `xattr -dr com.apple.quarantine <폴더 경로>`로 격리를 풉니다.
- **화면 및 시스템 오디오 녹음** 권한을 직접 허용해야 합니다. 와우는 창 모드(전체 창)로.
- 제 맥북 한 대에서만 테스트했습니다. 시행착오가 있을 수 있습니다.

# 처음 세팅
1. 와우에서 애드온을 켜면 **초록색 매트릭스 박스**가 보입니다. 잘 보이는 곳으로 드래그해서 옮기고 `/cm lock`으로 고정하세요. 다른 UI에 가려지면 안 됩니다. 다시 옮기려면 `/cm unlock`.
2. 프로그램을 켜면 번역창에 채팅이 나옵니다. 처음이거나 매트릭스 위치를 바꿨다면 번역창의 ⟳를 눌러 다시 찾습니다.
3. **색이 바뀌는 환경이면 색 단계를 낮추세요.** DLSS, HDR, 밝기, 색 필터가 있으면 매트릭스 색이 틀어져서 인식이 안 될 수 있습니다. 애드온 설정(ESC → 설정 → 애드온 → ChatMatrix)에서 컬러 레벨을 낮추거나 `/cm levels 16` (기본 256). 대부분 이걸로 해결됩니다. 안 되면 8, 4로 더 낮춥니다.
4. **맥북 레티나**는 기본값(x2)에서 256 레벨로는 인식이 안 됩니다. `/cm levels 16`으로 낮추세요.
5. `/cm`을 치면 모든 명령이 나옵니다. 채팅 필터는 `/cm filter`, 설정창은 `/cm config`.

# 번역 방식
옵션의 번역 탭에서 고릅니다.
- **구글 번역 (기본)**: 설정 없이 바로 됩니다. 맥락을 이해하는 수준은 아니지만 플레이에는 거의 문제가 없습니다. 제한에 걸리면(보통 다른 문제입니다) 구글 API 키를 직접 만들어 넣을 수 있습니다 (월 50만 자 무료, 이후 100만 자당 20달러). 키 없는 무료 번역은 공식 API가 아니라서 언제든 막힐 수 있습니다.
- **AI 서버 (OpenAI 호환)**: OpenAI 방식 API를 지원하는 서버면 됩니다. 클라우드 AI도, 내 PC의 로컬 AI도 됩니다.
- **직접 설정한 서버**: 요청 형식을 직접 적는 방식입니다 (예: Gemini).
- 번역 안 함: 원문만 보고 싶을 때.

# 로컬 AI로 번역하기 (LM Studio)
번역을 AI에게 시키면 기계번역과 차이가 큽니다. 게임 채팅이라는 걸 알고 번역하기 때문에 `LFM`, `HEAL`, `TANK` 같은 말을 알아서 "구인", "힐러", "탱커"로 옮기고, 단어장은 괄호 참조로 알려 주면 찰떡같이 알아듣습니다. 작은 모델이어도 단어장 처리는 기계번역과 비교가 안 됩니다.

와우가 VRAM을 보통 8GB쯤 쓰니, VRAM에 4GB 정도를 AI에게 더 주면 충분히 좋은 번역이 나옵니다. 번역만 시키는 거라 작은 모델과 가벼운 양자화로 타협해도 됩니다.

LM Studio 설치와 설정은 가이드로 정리해 놨습니다: [LM Studio로 로컬 AI를 돌려 번역하기](docs/LM%20Studio.md)

# 음성인식 (선택)
디스코드 같은 음성 대화를 Whisper로 글로 바꿔서 번역창에 띄웁니다. 소리는 내 PC 안에서만 처리되고 밖으로 나가지 않습니다.
- 옵션의 **음성인식** 탭에서 엔진과 모델을 "설치"하면 됩니다. 전부 프로그램 폴더의 `extensions/stt` 안에만 설치되고 삭제 버튼으로 지울 수 있습니다.
- 소리를 가져올 대상은 프로그램별(디스코드, 와우 등), 장치, 시스템 전체 중에서 고릅니다.
- **Windows 권장: Vulkan 엔진 + `large-v3-turbo` 모델.** GPU만 있으면 대부분의 PC에서 됩니다 (Nvidia, AMD, Intel 모두).
- 사양이 부담되면 **Vulkan 엔진 + `small` 모델**을 추천합니다.
- GPU가 없어서 CPU 엔진을 쓰면 `small` 이하가 현실적입니다. `turbo`는 CPU에서 실시간보다 느립니다. 음성인식 탭의 "모델 목록과 속도"에서 내 PC의 속도를 직접 재 볼 수 있습니다.
- CUDA 엔진은 예정입니다.

**Mac에서 음성인식**
- 엔진은 **Metal** 하나만 설치하면 됩니다. GPU(Metal)와 CPU가 한 파일에 들어 있어서, "계산 장치"에서 GPU나 CPU를 고를 수 있습니다. 어느 쪽이 나은지는 "모델 목록과 속도"에서 직접 재 보고 정하세요. 사양이 좋지 않으면 `small`을 쓰세요.
- GPU(Metal)로 처음 켤 때는 모델을 불러오는 데 10초쯤 걸립니다 (처음 한 번 GPU용 코드를 준비하는 시간입니다).
- 소리는 **화면 및 시스템 오디오 녹음** 권한으로 받습니다. 허용하지 않으면 소리를 받지 못합니다 (시스템 설정 → 개인정보 보호 및 보안).
- Mac은 프로그램 안의 소리를 더 나누지 못합니다. 대상을 디스코드로 두면 음성 대화뿐 아니라 디스코드가 내는 모든 소리(영상 등)가 같이 글로 나옵니다. 영상은 브라우저로 보면 서로 섞이지 않습니다.

# 업데이트
- 릴리즈 zip에는 `config.json`, 단어장, 글꼴이 들어 있지 않아서 **그냥 덮어쓰면 됩니다.** 애드온도 마찬가지입니다.
- 새 버전이 있으면 시작할 때 알림만 줍니다 (옵션에서 끌 수 있고 자동 설치는 없습니다).
- **1.x(Python 버전)에서 올라오는 경우**: 새 폴더에 풀고 이전 폴더의 `config.json`, `fonts` 폴더(와 `Glossary.txt`)만 복사하는 게 가장 깔끔합니다. 설정은 알아서 가져옵니다 (원본은 `config.1x.json`으로 남습니다). 이전 폴더에 덮어써도 됩니다. 처음 실행할 때 이전 버전 파일을 `old_version_backup` 폴더로 옮길지 묻습니다 (지우지 않고 옮기기만 합니다). 옮기지 않으면 프로그램이 시작되지 않습니다.

# 주의 사항
- 한계: 와우 한밤 확장팩 이후 애드온 검열이 강해져서 일부 메시지(길드 관리자, 전장, 보스 전투)는 수집할 수 없습니다. 안전망이 있어서 나머지는 전부 수집됩니다 (애드온 옵션에서 기타까지 체크하고, 본인의 채팅 필터 설정에 따라). 북미 서버에서는 크게 문제가 안 됩니다. 최근 공식 API 패치노트를 보면 후에 개선될 여지가 있습니다.
- 와우 리테일 본섭과 포에버는 제가 하고 있는 서버라 테스트됐습니다. 클래식이나 다른 것들은 미지수입니다. toc의 버전 호환성만 추가하면 될 가능성이 있습니다.
- Windows와 Mac 모두 테스트했습니다. Mac은 제 맥북에서만 해서 시행착오가 더 있을 겁니다.
- DLSS, HDR처럼 색을 바꾸는 후처리가 있으면 인식에 지장이 생길 수 있습니다. 위의 "처음 세팅"의 색 단계 조절로 대부분 해결됩니다 (와우 밝기를 100%까지 올려도 감지됩니다).

# 인터넷으로 나가는 것
- **번역**: 번역할 채팅 글이 내가 고른 번역 서비스(구글 번역, 또는 내가 설정한 AI 서버)로 갑니다. 번역을 끄면 나가지 않습니다.
- **새 버전 확인**: 시작할 때 GitHub 릴리즈 정보를 한 번 읽습니다 (끌 수 있음).
- **음성인식 설치**: 엔진은 이 저장소의 릴리즈에서, 모델은 Hugging Face에서 받습니다.
- 그 밖에는 아무것도 보내지 않습니다. 설정, 로그, 단어장은 프로그램 폴더 안에만 저장됩니다.

# 자주 하는 질문
- **어느 서버 하시나요?** 북미 리테일 티콘드리우스, 북미 포에버 PVP.
- **매트릭스 감지가 안 돼요**: 우선 정말 감지가 안 되는 건지 보세요. 대부분 애드온을 제대로 설치하지 않은 경우입니다. 애드온을 설치하고 잘 보이는 곳에 둔 뒤 번역창의 ⟳를 누르고, 그래도 안 되면 색 단계를 한 단계 낮춰서 다시 ⟳를 누릅니다.
- **구글 번역 제한이 걸렸어요**: 저는 일주일 내내 켜놔도 문제가 없었습니다. 정말 제한이면 같은 IP의 브라우저에서 구글 번역도 막혀야 정상입니다. 아니라면 구글 쪽 변경 때문일 수 있으니 이슈로 알려 주세요. 꼼수가 아니라 합법적인 방식만 씁니다.
- **와우 공식 폰트는 어떻게 구하나요?** 저작권 때문에 릴리즈에 넣을 수 없고, **인터넷에 공유된 "와우 폰트" 파일은 거의 다 이름만 같은 다른 폰트입니다** (제가 받아 본 것은 전부 아니었습니다. 한글이 비슷해 보여도 영어 모양이 다르거나, 아예 다른 글꼴이 들어 있습니다). **반드시 본인의 와우 클라이언트에서 직접 추출하세요.**
  1. 별도의 와우 파일 추출 프로그램(직접 찾아서 쓰세요)으로 내 와우 설치에서 `Fonts` 폴더의 `2002.TTF`(한국어 클라이언트)나 `ARIALN.TTF`(영어 클라이언트)를 꺼냅니다.
  2. 어떤 파일을 꺼내야 할지 모르겠다면 와우 채팅창에 `/run print(ChatFrame1:GetFont())`를 입력하세요. 채팅창이 쓰는 글꼴 파일의 경로가 나옵니다 (채팅 애드온이 글꼴을 바꿨다면 그 애드온의 글꼴 경로가 나옵니다).
  3. 꺼낸 파일을 `fonts` 폴더에 넣고 프로그램을 다시 켜면 옵션 → 창 → 글꼴에서 고를 수 있습니다. 목록의 이름은 파일 이름이 아니라 **파일 안에 적힌 글꼴 이름**입니다.
- **보내기(Shift+Enter)가 안 돼요**: 리더와 와우 중 한쪽만 관리자 권한이면 안 됩니다. 옵션에서 꺼져 있을 수도 있으니 옵션 → 보내기 탭을 확인하세요.
- **단어장은 없나요?** 제가 단어장을 공유하는 일은 아마 없습니다. 더 나은 규칙을 계속 제시할 겁니다. 서로 공유하거나 자신만의 단어장을 만들어 보세요.
- **원하는 것만 보고 싶어요**: 애드온과 리더 양쪽에 상세한 필터가 있습니다. 기본 옵션은 와우 기본 채팅탭을 따라가서, 처음에는 보기 싫은 것까지 다 뜹니다.
- **로컬 AI는 왜 안 넣어 주나요?** 계속 발전하고 바뀌는 것(번역 AI, 음성인식 모델)은 이 프로그램이 직접 구동하지 않고 외부 연결을 기본으로 합니다. 모델과 구동 방식은 매일 바뀌지만 연결 방법은 안 바뀝니다. 제가 언제 업데이트를 멈출지 모르니, 사용자가 시대에 맞춰 따라갈 수 있게 하는 쪽입니다.
- **그냥 뭐가 잘 안 돼요**: GPT나 제미나이 같은 AI에게 이 GitHub 페이지를 링크하고 도와달라고 하세요. 소스가 전부 공개되어 있어서 잘 분석해 줄 겁니다.

# 소스에서 빌드하기
Tauri v2(Rust + 순수 JavaScript)로 만들었습니다. 화면과 로직은 `app/`의 JavaScript이고, `src-tauri/`의 Rust 프로그램은 창과 OS 호출만 맡는 얇은 껍데기입니다.

필요한 것: Visual Studio Build Tools(C++를 사용한 데스크톱 개발), Rust(`rustup default stable-msvc`). 그다음 `build.bat`을 실행하면 `ChatMatrixReader.exe`가 만들어집니다 (`app` 폴더와 같은 곳에서 실행). 시험은 Node.js 18 이상으로 `node tests/run.mjs`입니다. 음성인식 엔진 소스는 `engine/stt/`(CMake, 자세한 것은 그 폴더의 README)에 있습니다. 플러그인 제작 가이드는 준비 중입니다 (`docs/`).
