# ChatMatrix Reader

월드 오브 워크래프트(WoW)의 채팅을 읽어서 **번역해 주는 투명한 창**을 게임 위에 띄우는 프로그램입니다. 게임 파일을 건드리지 않습니다. 와우용 **ChatMatrix 애드온**이 채팅을 화면 한쪽의 작은 색 칸(매트릭스)으로 그려 주면, 이 프로그램이 화면에서 그 칸을 읽어 글로 되돌리고 번역합니다.

> 이 프로그램은 Blizzard Entertainment와 제휴하거나 승인받은 것이 아닙니다. World of Warcraft는 Blizzard Entertainment의 상표입니다.

## 할 수 있는 것
- 채팅을 번역해서 게임 위의 투명한 창에 표시 (원문과 번역을 함께, 순서 바꾸기, 채널별 번역 방식)
- 번역창을 여러 개 만들고 창마다 채널, 글꼴, 크기, 투명도, 배경 흐림, 글자 외곽선을 따로 설정
- **항상 위**, **와우 위에만** 보이기, **클릭 관통**(게임 조작 방해 없음, 키를 누르고 있을 때만 창 조작)
- 단어장(번역 규칙), AI 번역 서버(LM Studio, OpenAI 호환) 또는 구글 번역
- `Shift+Enter`로 내가 쓴 글을 번역해서 채팅창에 붙여넣기 (보내기)
- **음성인식(선택)**: 디스코드 같은 음성 대화를 Whisper로 글로 바꿔 번역창에 표시 (Windows, 별도 설치)
- 옵션은 바꾸는 즉시 반영됩니다. 옵션 열기: 번역창의 ⚙, 트레이 아이콘, 또는 `Ctrl+Alt+O`

## 설치와 실행 (Windows)
1. 릴리즈 페이지에서 `ChatMatrixReader-v<버전>-windows-x64.zip`을 받아 **원하는 폴더에 풉니다.** 설정 파일과 로그는 이 폴더 안에 생깁니다.
2. 폴더의 `ChatMatrixReader.exe`를 실행합니다. 서명되지 않은 프로그램이라 Windows가 경고를 보일 수 있습니다: "추가 정보 → 실행".
3. 와우를 **창 모드 또는 전체 창 모드**로 실행합니다 (전용 전체 화면에서는 다른 창이 위에 보이지 않습니다).
4. 와우에서 ChatMatrix 애드온을 켜면 번역창에 채팅이 나옵니다. 처음 실행했거나 매트릭스 위치를 옮겼다면 번역창의 ⟳를 눌러 매트릭스를 다시 찾으세요.

필요한 것: Windows 10 또는 11, WebView2 런타임(Windows 11에는 들어 있습니다. Windows 10에서 프로그램이 뜨지 않으면 Microsoft의 WebView2 런타임을 설치하세요).

**1.x(Python 버전)에서 올라오는 경우:** 새 폴더에 풀고 이전 폴더의 `config.json`과 `fonts` 폴더(단어장 `Glossary.txt`도)만 복사해 오는 것이 가장 깔끔합니다. 설정은 3.0이 알아서 가져옵니다 (원본은 `config.1x.json`으로 남습니다). 이전 폴더에 그대로 덮어써도 됩니다: 처음 실행할 때 이전 버전의 파일을 알아보고 `old_version_backup` 폴더로 옮길지 묻습니다 (지우지 않고 옮기기만 하며, 설정과 글꼴은 그대로입니다). 옮기지 않으면 프로그램이 시작되지 않습니다.

프로그램을 지우려면 폴더를 지우면 됩니다. 레지스트리나 다른 곳에 아무것도 남기지 않습니다.

## 음성인식 (선택)
옵션의 **음성인식** 탭에서 "설치"를 누르면 음성인식 엔진과 모델을 내려받습니다 (모두 프로그램 폴더의 `extensions/stt` 안에만 설치되고, 삭제 버튼으로 지울 수 있습니다). Whisper는 이 PC에서 소리를 인식하므로 소리가 밖으로 나가지 않습니다.
- 엔진: CPU용과 GPU(Vulkan)용. 모델은 Whisper(Hugging Face의 whisper.cpp 저장소)에서 받으며, 받은 파일은 SHA-256으로 확인합니다.
- 대부분의 PC에서는 **GPU(Vulkan) 엔진 + `large-v3-turbo` 모델**을 권장합니다. GPU가 없으면 `small` 이하가 현실적입니다. 음성인식 탭의 "모델 목록과 속도"에서 내 PC의 속도를 직접 재 볼 수 있습니다.

## macOS (실험적)
Apple Silicon(M1 이후) Mac용 실험 버전이 있습니다. 번역창, 항상 위, 와우 위에만, 클릭 관통, 매트릭스 읽기가 동작하며 **음성인식은 아직 지원하지 않습니다(지원 예정)**. 개발자 등록을 하지 않은 프로그램이라 처음 실행할 때 보안 경고가 나오고(우클릭 → 열기), **화면 및 시스템 오디오 녹음** 권한을 직접 허용해야 합니다. 와우는 창 모드(전체 창)로 실행하세요. 매트릭스가 안 읽히면 애드온의 색 단계를 낮춰 보세요(`/cm levels 8`).

## 인터넷으로 나가는 것
- **번역:** 번역할 채팅 글이 내가 고른 번역 서비스(구글 번역, 또는 내가 설정한 AI 서버)로 전송됩니다. 번역을 끄면 나가지 않습니다.
- **새 버전 확인:** 시작할 때 GitHub 릴리즈 정보를 한 번 읽습니다 (옵션에서 끌 수 있고, 알림만 주며 자동 설치는 없습니다).
- **음성인식 설치:** 엔진은 이 프로그램의 GitHub 릴리즈에서, 모델은 Hugging Face에서 받습니다.
- 그 밖에는 아무것도 보내지 않습니다. 설정, 로그, 단어장은 프로그램 폴더 안에만 저장됩니다.

## 문제가 생겼을 때
옵션 → **정보** → 로그에서 최근 기록을 복사해서 알려 주세요. 파일은 프로그램 폴더의 `logs/chatmatrix.log`입니다.

## 소스에서 빌드하기
Tauri v2(Rust + 순수 JavaScript)로 만들었습니다. 화면과 로직은 `app/`의 JavaScript이고, `src-tauri/`의 Rust 프로그램은 창과 OS 호출만 맡는 얇은 껍데기입니다.

필요한 것: Visual Studio Build Tools(C++를 사용한 데스크톱 개발), Rust(`rustup default stable-msvc`). 그다음 `build.bat`을 실행하면 `ChatMatrixReader.exe`가 만들어집니다 (`app` 폴더와 같은 곳에서 실행). 시험은 Node.js 18 이상으로 `node tests/run.mjs`입니다. 음성인식 엔진 소스는 `engine/stt/`(CMake, 자세한 것은 그 폴더의 README)에 있습니다. 플러그인 제작 가이드는 준비 중입니다 (`docs/`).
