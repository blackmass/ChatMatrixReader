# ChatMatrix Reader — macOS (첫 버전, 실험적)

## 실행
1. 압축을 풀고 `ChatMatrix Reader.app`을 더블클릭 (처음엔 우클릭 → 열기). 첫 실행만 터미널 창이 잠깐 열려 설치합니다.
2. 처음 실행 때 필요한 것(numpy, pyobjc)을 `.venv`에 자동 설치합니다 (맥에서만, 한 번).

## 필수 설정
* 와우는 **창 모드 / 전체 창(Windowed Fullscreen)** 만 지원합니다. 전용 전체화면은 안 됩니다.
* 애드온 ChatMatrix: `/cm levels 8` (또는 16). 맥은 색 보정(Display P3) 때문에 256단계(v1)는 읽을 수 없습니다.
* 시스템 설정 → 개인정보 보호 및 보안:
  * **화면 및 시스템 오디오 녹음**: Terminal(또는 실행한 앱) 허용 — 화면의 매트릭스를 읽는 데 필요
  * **입력 모니터링**: 보내기 번역(Shift+Enter)을 쓸 때만 필요
  * 권한을 준 뒤에는 프로그램을 한 번 다시 시작해야 적용됩니다.

## 맥에서 다른 점
* 전역 단축키(Ctrl+Alt+O) 없음 → 옵션은 우클릭, ⌘+, , 메뉴 막대 "CM", 클릭 통과 중에는 Shift를 누른 채 창 위에서 조작.
* 와우가 활성 창이면 맨 위, 다른 프로그램이 활성이면 와우 창 바로 위에 놓입니다 ("와우 창 위에만" 옵션).
* 아직 검증되지 않은 부분: 창 모양/투명도, 와우 따라가기, 메뉴 막대 아이콘, 보내기 번역.
