글꼴 넣는 곳 / Put your fonts here

번역창에 쓰고 싶은 글꼴 파일(.ttf .otf .woff2)을 이 폴더에 넣으세요.
그다음 옵션 창을 다시 열면 옵션 > 창 > 글꼴 목록에 "글꼴 이름 — 파일 이름"으로 나옵니다. 고르면 바로 번역창에 적용됩니다.

- 파일 이름에 한글이나 공백이 있어도 됩니다.
- 이 폴더의 글꼴은 프로그램과 함께 배포되지 않습니다. 글꼴의 사용 조건은 각 글꼴의 라이선스를 따르세요.
- 윈도우에 설치된 글꼴은 여기에 넣지 않아도 목록에 있습니다.

Put the font files (.ttf .otf .woff2) you want to use in the translation window into this folder,
then open the options window again: they appear under Options > Windows > Font as "font name - file name".
The fonts in this folder are not part of the program; follow the license of each font.
